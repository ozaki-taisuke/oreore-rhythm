# オレオレリズム 🥁

きいて → こたえて、の コール&レスポンス リズムゲーム。
まんなかの子（まと）を、おなじリズムで タップしよう。

- **あそびかた**: `index.html` を ブラウザで ひらくだけ。スマホOK・よこもちOK
- **つうしん なし・データしゅうしゅう なし**。ぜんぶ きみの たんまつの なかで うごく
- 音は ぜんぶ その場で 合成（おんげんファイルなし）

## ルールは 3つだけ

1. **タン**の リズムは、おなじように たたく
2. ひくい**「ダ」**の 音は、まねしない（的は 来るけど、たたかない！）
3. **「しーっ」**が 聞こえたら、つぎの 小節は まるごと がまん

まとの **外**は ジャム席。すきに たたいて OK（場所で 音が 変わるよ）。
でも、まとへの れんだだけは……👀 おみとおし。

## じぶんに あわせる（⚙）

- **にゅうりょく**: まと／パッド（親指ゾーン。みぎ・ひだり・した）／ぜんぶ
- **おと補正**: イヤホンや Bluetooth で「合ってるのに おそい」が出たら ＋方向へ
- **ジャスト窓**: はんていの きびしさ
- **わなヒント**: わなの的を 赤い てんせんで 表示（なれるまでの ほじょりん）
